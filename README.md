# School Life

School Life is a top-down RPG game inspired by Undertale and Pokemon, designed to simulate college life. The game is developed using Processing and features various activities like studying, eating, socializing, and sleeping, each affecting the player's stats and progress through the semester.

## Features

- **Player Management**: Control a character, navigate the map, and interact with the environment.
- **Activities**: Engage in activities such as studying, eating, socializing, and sleeping to manage your stats.
- **Day and Week Tracking**: Keep track of the days and weeks of the semester.
- **Battles**: Face various challenges and battles that simulate tests and projects.
- **Stat Management**: Manage your intelligence, happiness, and health to survive the semester.

## Getting Started

### Prerequisites
- [Processing](https://processing.org/download/) installed on your computer.

### Installation
1. **Clone the repository**:
    ```sh
    git clone https://github.com/JasonAK19/School-Life.git
    ```
2. **Open the project in Processing**:
    - Open Processing.
    - Open the `schoolLife.pde` file from the cloned repository.

### Running the Game
1. Click the **Run** button in Processing to start the game.
2. Follow the on-screen instructions to navigate through different stages and manage your stats.

## Game Controls

- **WASD Keys**: Move the player character.
- **Mouse Click**: Interact with buttons.
- **Key 0**: Trigger a specific game event.
- **Key 9**: Trigger a specific game event.
- **Key L**: Maximize all stats.
- **Key M**: Trigger a specific game event.
- **Key P**: Skip to the end of the semester.

## Game Stages

1. **Start Screen**: Displays the game title and prompts the player to start.
2. **Main Stage**: The primary gameplay stage where the player can choose various activities.
3. **Activity Stages**: Different stages for studying, eating, and socializing.
4. **Battle Stages**: Various stages for different battles and challenges.
5. **End Stages**: Stages that display the result of the semester based on the player's stats.
